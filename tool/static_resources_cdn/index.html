静态资源 CDN 公共库

简介​

内容分发网络（CDN）是一种通过分布在多个地理位置的服务器网络，快速提供互联网内容的服务。使用CDN托管静态资源可以显著提高网站的加载速度，减少服务器负载，并提升用户体验。
